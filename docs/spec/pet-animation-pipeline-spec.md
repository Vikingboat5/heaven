# 宠物动画管道 Spec (v1.0, 2026-09-12 拍板)

> 地位：宠物动作的内容与工艺的唯一依据。新增动作/新物种适配，先改本文件。
> 落地：动作设计表 `backend/app/content/animation_designs.json`，首尾帧生成 `scripts/gen_animation_frames.py`，采帧 `scripts/video_to_frames.py`。

## 1. 管道全景

```
孵化 → [S1] petgen 精灵表(形象) → [S2] 动作首尾帧设计(i2i, 自动)
     → [S3] 视频生成(当前人工控制台, API 开通后自动) → [S4] 采帧+抠图+QC → manifest → 游戏
```

- **S2 全自动**：宠物诞生后自动为标配动作集生成首尾帧（图片 i2i 链路已通）
- **S3 当前人工**：`Doubao-Seedance-1.5-Pro` 需标准端点开通（2026-09 排查：Agent Plan 不含视频模型；标准 key 未开通模型权限——开通后改自动）。人工交接面：首帧/尾帧 PNG 在 `backend/static/pets/{id}/_anim_pending/`，生成的 mp4 放回同名目录，跑 `video_to_frames.py` 采收
- **S4 全自动**：采帧/抠图/QC/目检拼图全本地零 token

## 2. 标配动作集（每宠必出）

| 动作 | 作用 | 触发时机 | 优先级 |
|------|------|---------|--------|
| `idle` 待机 | 在家的基础循环（呼吸感） | 常驻 | P0 |
| `wave` 归来问候 | 回家打招呼 | 旅行归来进主页那一刻播一次 | P0 |
| `petted` 被摸 | 触摸响应（歪头/眯眼蹭） | 点击宠物 | P1 |
| `sleep` 打盹 | 夜间困倦感 | 生活动作编排（夜间加权） | P1 |
| `eat` 进食 | 吃东西 | 归来带口粮/喂食后 | P2 |

原则（参考旅行青蛙/月兔/猫咪后院）：
1. **动作有叙事**——有开始/进行/结束，不是无限循环（idle 除外）
2. **动作绑场景锚点**——不悬空做动作（sleep 在巢边、eat 在空地）
3. **节奏是礼物**——生活动作间隔触发不刷屏；稀有动作（如写日记）≤2% 概率
4. **idle 永远可被打断**——任何动作播完/被点都先回 idle

## 3. 物种适配（铁律：鱼不招手）

动作模板按物种路由，不允许跨物种硬套（鱼在鱼缸里吐泡泡，不挥手）。`animation_designs.json` 按物种关键词匹配：

| 物种关键词 | idle | wave | petted | sleep | eat |
|-----------|------|------|--------|-------|-----|
| 狐/犬/狼 | 摇尾巴+眨眼 | 站立挥手 | 歪头眯眼 | 蜷成一团 | 啃食 |
| 猫 | 轻摆尾尖 | 抬爪招 | 蹭手呼噜 | 揣手手趴 | 舔食 |
| 兔 | 抖鼻+竖耳 | 蹦跳 | 耳朵贴头 | 缩成球 | 啃萝卜状食物 |
| 鱼/水生 | 吐泡泡+摆尾 | 上下游动 | 贴缸壁 | 悬停缓沉 | 啄食 |
| 鸟 | 梳羽 | 扑翅 | 低头求摸 | 单腿站立埋首 | 啄食 |
| 默认(其他) | 轻晃+眨眼 | 招手 | 闭眼享受 | 趴下 | 啃食 |

## 4. Prompt 调优规则

首尾帧 prompt 必须同时满足三层一致：
1. **形象一致**：i2i 参考 `idle_0.png`（毛色/长相/画风锁死），prompt 里复述 `pet.appearance`
2. **画风一致**：水彩绘本风关键词固定（`手绘童话插画风, 暖色调, 水彩质感`），白底无影无框
3. **动作匹配物种**：动作描述词从 §3 物种表取，禁止跨物种

视频 prompt（S3 控制台用）= `首帧到尾帧的过渡动作描述 + 镜头固定 + 纯白背景 + 循环感`，由 gen_animation_frames.py 一并产出到 `_anim_pending/{action}.txt`，用户/未来 API 直接取用。

## 5. QC 与验收

- 首尾帧：目检角色一致性（i2i 偶有漂移，漂移就重生成）
- 采帧后：抠图三层净化（影子/描边/浅色残留），contact.png 拼图画检
- 播放验收：主页实机——画风统一、无白底、循环自然、动作与场景锚点吻合

## 6. 规模化备注

- 视频生成是**成本大头**（按秒计费）：标配 5 动作 × **4s** = 20s/宠（2026-09-12 注：AtlasCloud 档位下限 4s；慢速环境动作 4s 足够一次完整过程）。冷启动期人工控制台生成，量产期必须 API 化 + 成本熔断（复用 llm 网关的 budget 机制）
- **供应商**（2026-09-12 拍板）：AtlasCloud `bytedance/seedance-2.0-mini/image-to-video`（首尾帧 i2v，支持 base64 直传）。方舟 Agent Plan 不含视频模型、标准 key 未开通模型权限，已弃用该路
- **角色一致性资产化**：AtlasCloud Asset Library——每只宠物的参考图注册一次（`asset://<id>`），之后所有视频生成引用该资产，不必重复传图；量产期必做
- 视频 prompt 采用**时间轴分段结构**（0-1s 准备 / 1-3s 动作 / 3-4s 收尾），比单句描述更稳
