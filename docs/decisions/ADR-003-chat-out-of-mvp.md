# ADR-003: 对话功能移出 MVP（2026-08-23 拍板）

## 背景
MVP 原定「主页 = 宠物 + 对话入口」。E2E 走查时负责人拍板：对话涉及**用户自由文本输入**，国内上线面临内容安全审核（UGC 对话需备案/审核机制），MVP 阶段风险不可控。

## 决策
1. **对话（/chat、对话 API）移出 MVP 范围**，作为后续拓展方向保留
2. 入口全部撤下：顶部导航「对话」、主页「和TA聊聊」CTA；`/chat` 路由重定向回主页
3. **代码不删**：`ChatView.vue`、`/api/dialogue/*`、LLM gateway 保留（对话日记 prompt 能力仍是核心资产——旅行日记润色仍在用 LLM）
4. 旅行中"聊天锁定"逻辑保留备用（重新上线时直接恢复）
5. 同时拍板主页布局红线（E2E 走查发现）：**底部操作坞、归来信封、拆开后的信件均不得遮挡宠物形象**——宠物是画面主角，UI 元素让位（操作坞紧凑半透明贴底；信封在宠物旁侧；信件为底部抽屉式信纸）

## 影响
- MVP 交互闭环变为：照料蛋 → 孵化 → 看它生活/旅行 → 打包行囊 → 收信/收集图鉴
- 社交 readiness（ADR-002 §10）不受影响
- 后续若上对话：需先解决内容审核方案（输入过滤 + 输出审核 + 可能的话改用选项式互动代替自由输入）
