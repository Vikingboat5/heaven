# ADR-001: 极简重构 —— 删除喂食/休息/任务/心情，冒险旅行青蛙化

- 日期：2026-08-17
- 状态：已拍板并实施（P1-P4 已提交，见 git log）
- 关联：spec v1.0 → v1.1（`docs/spec/mvp-spec.md` 变更记录）

## 背景

MVP 功能面铺得过宽：喂食/休息（日限次打工感）、任务系统（3 日常+3 成就）、心情/饱食/精力三状态（惰性衰减）。这些系统相互之间以及与"它活着"的核心情感定位耦合薄弱，维护成本高，且任务领取等链路已出现过真实 bug（2026-08-16 任务领取不刷新修复）。

## 决策

**删繁就简，主循环收敛为：看宠物形象 ↔ 对话；宠物自主出门旅行（旅行青蛙/月兔旅行式）。**

删除：
- 喂食/休息接口与 UI（`/api/pets/feed`、`/api/pets/rest`、主页按钮）
- 任务系统全部（api/services/models/TasksPanel/事件钩子/测试/验证脚本）
- 心情/饱食/精力三状态（衰减、`Pet.state` 列、对话 +心情、persona 状态注入）

升级：
- 离线探险 → **旅行状态机**：离线 ≥45min 自动出门 / 手动送出门；旅行 2-6h；旅行中主页空房+倒计时、对话锁定；归来结算旅行日记（LLM 润色，模板降级）+ 纪念品 + 经验，回归卡片展示

重定义（原描述引用了已删除机制）：
- 天赋「好胃口」：进食恢复心情+20% → **旅途中更爱觅食，常带回食物纪念品**（觅食权重 12→20）
- 天赋「打盹高手」：休息精力恢复+15% → **旅途中打盹也能攒灵感**（休息事件经验 2→5）

## 备选方案与取舍

| 方案 | 不选的原因 |
|------|-----------|
| 保留任务系统只修 bug | 任务与"悠闲陪伴"调性冲突，且是 bug 高发面 |
| 保留心情但隐藏数值 | 隐形状态不可解释，对话语气调制收益低 |
| 旅行中不锁对话 | 旅行青蛙的"等待感"是情感核心；外出锁对话制造想念 |

## 影响

- 背包纪念品**只进不出**，暂无消耗出口
- 经验唯一来源 = 旅行结算；等级仅解锁旅行区域
- V1.0 一人限一宠，无再获蛋途径（与 D1/D2 一致）
- 对话成为唯一主动互动 → 主动搭话（D6）、轮次限制（D3）优先级上升

## 待评估（未拍板）

1. **打包行囊**：把纪念品交给宠物影响下次旅行（目的地/时长/收获）——旅行青蛙玩家唯一的主动操作，是否引入
2. 旅行中"远程想念"式短对话（打破锁定）
3. 本地 PostgreSQL 旧库的 `pets.state` / `pets.state_updated_at` / `tasks*` 表清理（模型已移除列，旧列残留无害，重装即消）
